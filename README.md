# Todo Manager

A clean, responsive, and easy-to-use task management application built with React and Tailwind CSS.

## Features

- Add new tasks
- Mark tasks as completed or active
- Delete tasks
- Responsive design for mobile and desktop

## Tech Stack

- React
- Vite
- Tailwind CSS

## Installation

1. Make sure you have Node.js installed.
2. Clone this repository.
3. Install dependencies:

```bash
npm install
```

## Running the Application

To start the development server:

```bash
npm run dev
```

Then, open your browser and navigate to `http://localhost:5173` (or the URL provided in your terminal).

## Build for Production

To create a production build:

```bash
npm run build
```

This will generate a `dist` folder with the optimized static assets.
